# مساعد Hamdi Photography المحلي

المساعد يجيب داخل المتصفح بردود جاهزة عن الخدمات والأسعار والحجز، ولا يرسل أسئلة الزبائن إلى OpenAI أو أي خدمة ذكاء اصطناعي.

## الحجز والتواصل

نموذج الحجز ينشئ رسالة جاهزة تحتوي الاسم ونوع الجلسة والباقة والتاريخ والوقت والتفاصيل. يختار الزبون إرسالها عبر WhatsApp أو SMS، ثم يراجعها ويضغط إرسال بنفسه. هذا طلب حجز فقط؛ حمدي يؤكد توفر الموعد بعد استلامه.

إرسال الرسائل يحتاج اتصالًا بالإنترنت وتطبيق WhatsApp أو SMS على جهاز الزبون. الموقع لا يرسل الرسائل تلقائيًا.

## Cloudflare Worker

لم يعد Worker يتصل بـOpenAI؛ مسار /api/chat متوقف، ويبقى فحص /api/health فقط. لا حاجة إلى مفتاح OPENAI_API_KEY لهذا الإصدار. إذا أُضيف المفتاح سابقًا، احذفه يدويًا من Worker Settings ثم Variables and Secrets.
