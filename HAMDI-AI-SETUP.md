# Hamdi AI — Bland integration plan

This branch prepares the Hamdi Photography website for a Bland web-chat integration. The live `main` branch is not changed by this work.

## Current status

- The existing website assistant is a local FAQ script; it is not connected to an AI service.
- The published Bland Web Chat widget's official embed configuration has been added to `bland-widget.js` using the widget ID generated by the account. The live website has not been updated; this change is on the feature branch only.
- No Bland API key, phone number, WhatsApp token, or other secret belongs in this repository.
- No phone calls, paid services, or messages are activated by this branch.

## Recommended architecture

1. **Website chat:** create and publish a Bland Web Chat widget in the Bland dashboard. Enable voice input in the widget settings if that feature is available for the selected account/plan.
2. **Allowed domain:** allow only the production GitHub Pages origin:
   `https://hamdihajiali3-cell.github.io`
   Add a custom domain separately only if one is configured later.
3. **Agent behavior:** set the agent name to **Hamdi AI**. Use Arabic as the default language, and configure Turkish and English responses. The agent should match the visitor's language, identify itself as an AI assistant, answer only from approved photography-service information, and hand uncertain pricing/availability questions to Hamdi.
4. **Booking intake:** collect only the minimum necessary details: name, contact method, requested service, preferred date/time, city/area, and optional budget. Do not claim a booking is confirmed until Hamdi confirms it.
5. **Location:** a phone call does not grant GPS access. For precise location, send a separate HTTPS form link and ask the customer to share location voluntarily. Offer a typed address as an alternative.
6. **Phone channel:** configure an inbound number only after checking that Bland or its supported telephony provider can provision and operate a Turkish number for this account. Test inbound and outbound calls before advertising the number.
7. **WhatsApp notification:** use an approved WhatsApp Business Platform integration or an authorized provider, through a backend. Do not automate WhatsApp Web.
8. **Backend:** use a server-side endpoint (for example, a Cloudflare Worker) for webhooks and notifications. Store API credentials as server-side secrets, never in browser JavaScript or GitHub Pages files.

## Privacy and safety defaults

- Tell visitors they are speaking with an AI assistant.
- Before recording calls or retaining transcripts, present the required notice and obtain any required consent.
- Explain what booking information is collected and why.
- Do not collect sensitive identity documents or payment-card details.
- Restrict access to booking data and define a retention/deletion policy.
- Never send a call, WhatsApp message, or paid API request during testing without explicit authorization.

## Dashboard setup checklist

In the Bland dashboard:

- Create a Web Chat widget attached to the Hamdi AI agent/pathway.
- Configure the published website origin in the widget's allowed domains/origins.
- Set the widget's greeting, appearance, and language behavior.
- Enable voice input if supported by the selected widget configuration.
- Test Arabic, Turkish, and English conversations using the dashboard preview.
- Copy the exact installation snippet generated by Bland.

The account-generated embed snippet was supplied and added to `bland-widget.js` as the official loader URL plus its public widget ID. Confirm the widget renders correctly on the staging/preview site before merging.

## Final activation gates

The integration is ready for production only after:

- The official Bland embed snippet is installed and tested on a staging copy.
- The widget works on desktop and mobile without hiding the existing booking form.
- The three languages pass a scripted test set.
- The phone-number country support and pricing are verified in the account.
- The webhook/backend and WhatsApp provider are configured with server-side secrets.
- Privacy notices and consent flows are reviewed.
- Hamdi approves merging the branch into the live site.
