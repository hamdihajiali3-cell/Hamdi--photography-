# Hamdi Photography

موقع تصوير وحجز خدمات Hamdi Photography في **غازي عنتاب، تركيا**.

- خدمات التصوير: بورتريه، تخرّج، الحلاقة وقصّات الشعر، صور الجواز والهويات، وتعديل ألوان الصور.
- نسختان: العربية والتركية.
- «نور» مساعدة صوتية للاستفسارات العامة، ونموذج منفصل لطلب التنسيق.
- إرسال طلب جلسة لا يضمن تأكيد الموعد؛ يتم الاتفاق مع الاستوديو مباشرة.
- معرض الصور يبقى مخفيًا حتى تتوفر أعمال تصوير حقيقية بإذن أصحابها.

لا توجد أسعار محددة منشورة على الموقع، ولا ينبغي تخمينها.
